# Math / Physics Session

CC-таught session per the player's track — математика или физика, протокол общий для всех игроков (стандарт S1–S9 Николь). План = карта и статусы; месячный лог в `diagnostics/` = fact side.

## Reads — до первой задачи

- `plans/{math|physics}-track-{player}.md` — трек предмета сессии: фаза/дорожка, статусы, §Ритм и механика
- `diagnostics/{player}_{math|physics}_session-log_YYYY-MM.md` — «План на следующую сессию» = агенда по умолчанию; новый месяц — новый файл той же структурой
- `diagnostics/nicole_{math|physics}_ru_terms.md` — для терм-блока (Николь)
- **Модель — жёсткое правило**: на **opus-5 не вести**; opus 4.8 — не замена, тот же баг (anthropics/claude-code#64076). Счёт 30.08: opus-5 — 4 фабрикации · fable-5 — ~20 утечек (S17, см. Fabrication guard) · sonnet-5 — 0. Рабочие: `claude-sonnet-5`, `claude-fable-5`. Стартовала на opus-5 — сказать Артёму, не начинать до `/model claude-sonnet-5`. Хук — страховка, не разрешение.

## Протокол

1. **Старт без мёртвого времени**: разминочная задача в чат сразу; параллельно поднять свежую Excalidraw-комнату («Онлайн взаимодействие» → «Начать сеанс»), ссылку для планшета отдельной строкой; браузерную панель держать открытой (иначе снимки не снимаются). Комната одноразовая.
2. **По одной задаче**: вопрос → ждать → реакция → следующая. Без пакетов и анонсов следующих заданий/целевых навыков.
3. **Показ → сама**: демо только на явно помеченных демо-задачах (максимум три); её задачу учитель не дорешивает; ответ открытого задания на экран не попадает.
4. **Холодные проверки**: сначала «реши, как умеешь», показ после. Канал ответа (чат / доска / бумага) называется прямо в задании.
5. **Дозировка ритуалов**: полный «ищу → считаю → ответ» — на одной контрольной задаче за сессию + корректирующе после диагонального чтения; ритуал финиша («сократил? записал нормально?») и формат записи — цикл «показ → угасающий намёк» (после показа 1–2 сессии прямо, потом намёк; не сработал → снова показ). На бумажных прогонах — на всех задачах.
6. **Анонс длины — асимметричный**: короткую продавать длиной («всего три задачки»); у длинной длину вперёд не называть, вести блоками и маркерами прогресса; на прямой вопрос — честно в блоках.
7. **Метод проверяется только явным вопросом**: на новых типах — «как ты это нашла?»; при неверном ответе первый ход — нейтральный «покажи, как считала». Любой её итог пересчитать до реакции.
8. **Разминка**: терм-микроблок 2–3 мин (2–3 термина циклом «назови / что это / мини-задача», новых ≤1–2; учитель говорит только терминами) + с сентября жанр-разминка — 2 микро-жанровые задачи по ротации из плана (только math).
9. **Физика**: новые термины — показом группами с немедленным использованием, холодных проверок на первом предъявлении нет (слой пуст); терм-микроблок проверяет только введённое ранее; ритуал финиша включает «ответ с единицей». На «не помню» первый ход — английский якорь («по-английски — первая буква?»), показ после; алфавит повторяется через «дано» задач, не карточками.
10. **RU-микропоправки (Николь; решение 24.08)**: явную ошибку-правило («в двое», «незнаю») можно поправить одной строкой в скобках после «✅ верно», максимум 1–2 за сессию, без встречного вопроса; опечатки и места рядом с математической ошибкой/затыком не трогать. Остальное — молча в harvest-лог. Сообщения станут короче — правило снять.

## Fabrication guard

Каждое сообщение заканчивается вопросом — **никакого текста после него**: «жду»-заглушки запрещены (~20 утечек S17 — «um‹ответ›»/«user …» именно там); реплики игрока не пишутся никогда, даже как пример без пометки «демо». Сработал хук — процитировать, переспросить, ничего не засчитывать. Перед логированием сверить засчитанное с user-записями сырого JSONL и собственные сообщения на строки-ответы после вопроса (`^um`, `^user`): ответ на экране до её реплики = зачёт аннулирован, задача сожжена, перечек только на новых числах/задачах; расхождения — инцидент-блоком.

## Логирование — после сессии

Запись в месячный лог той же структурой: **Тайминг** из таймстемпов транскрипта (общая + по блокам; длинные паузы — «пауза, причина неизвестна», не «долго думала») · таблицы результатов · Ошибки · Паттерн · План на следующую сессию. Статусы тем в плане (A/B, ru_terms) обновить при закрытии/продвижении; история — в логе.

**RU-harvest (Николь)**: тем же проходом по JSONL собрать орфографические ошибки её сообщений в `diagnostics/nicole_ru_writing_from_sessions.md` (правила отбора — в шапке файла; опечатки/пунктуация чата — шум). Её письмо в сессиях = холодное производство русского для RU-трека.

## Forbidden

- Пакетировать задачи; спойлерить следующие задания или целевой навык
- Дорешивать её задачу; ответ открытого задания на экране
- Демо до холодной проверки
- Фрейм «новый приём» для форматных тем — подавать как «так требуют записывать на контрольной»
- Мышь для письменной работы; бумага+фото — только таймированные прогоны и пробники
