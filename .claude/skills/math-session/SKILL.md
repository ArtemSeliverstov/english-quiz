# Math / Physics Session

CC-таught session per the player's track — математика или физика, протокол общий. План = карта и статусы; месячный лог в `diagnostics/` = fact side. Протокол ниже — стандарт, выработанный на S1–S9 Николь; действует для любого игрока и предмета.

## Reads — до первой задачи

- `plans/{math|physics}-track-{player}.md` — трек предмета сессии: фаза/дорожка, статусы, §Ритм и механика
- `diagnostics/{player}_{math|physics}_session-log_YYYY-MM.md` — «План на следующую сессию» прошлой записи = агенда по умолчанию; новый месяц — новый файл той же структурой
- `diagnostics/nicole_{math|physics}_ru_terms.md` — для терм-блока (Николь)
- **Модель — жёсткое правило**: сессии на **opus-5 не вести**. Счёт 2026-08-20: opus-5 — 4 фабрикации (math S6, S7, физика S1 ×2), sonnet-5 и fable-5 — 0. Рабочие модели: `claude-sonnet-5`, `claude-fable-5`. Старший opus (4.8) заменой не считается — открытый баг того же семейства (anthropics/claude-code#64076). Стартовала на opus-5 — сказать Артёму до первой задачи и не начинать содержание, пока не переключено: `/model claude-sonnet-5`. Хук `detect_fabricated_turns.js` — страховка, не разрешение.

## Протокол

1. **Старт без мёртвого времени**: разминочная задача в чат сразу; параллельно, если в агенде письменная работа — поднять свежую Excalidraw-комнату (excalidraw.com → «Онлайн взаимодействие» → «Начать сеанс»), ссылку для планшета отдельной строкой; браузерную панель держать открытой, иначе снимки не снимаются. Комната одноразовая.
2. **По одной задаче**: вопрос → ждать → реакция → следующая. Никаких пакетов, никаких анонсов следующих заданий и целевых навыков.
3. **Показ → сама**: демо только на отдельных, явно помеченных демо-задачах (максимум три); её задачу учитель не дорешивает никогда; ничего, что раскрывает ответ открытого задания, на экран не попадает.
4. **Холодные проверки**: сначала «реши, как умеешь», показ после. Канал ответа (чат / доска / бумага) называется прямо в задании.
5. **Дозировка ритуалов**: «ищу → считаю → ответ» полностью — на одной контрольной задаче за сессию, плюс корректирующе после эпизода диагонального чтения; ритуал финиша («сократил? записал нормально?») и формат записи — цикл «показ → угасающий намёк»: после показа 1–2 сессии строчки называть прямо, потом намёк; намёк не сработал → снова показ. На бумажных прогонах — на всех задачах.
6. **Анонс длины — асимметричный**: короткую продавать длиной («всего три задачки»); у длинной длину вперёд не называть, вести блоками и маркерами прогресса; на прямой вопрос — честно в блоках.
7. **Метод проверяется только явным вопросом**: на новых типах — «как ты это нашла?»; при неверном ответе первый ход — нейтральный «покажи, как считала» (S8/S9: дважды вскрыл и починил без разбора). Любой её итог пересчитать до реакции.
8. **Разминка**: терм-микроблок 2–3 мин (2–3 термина циклом «назови / что это / мини-задача», новых ≤1–2; учитель говорит только терминами) + с сентября жанр-разминка — 2 микро-жанровые задачи по ротации из плана. Жанр-разминка — только math.
9. **Физика**: новые термины вводятся показом группами с немедленным использованием — холодных проверок на первом предъявлении нет (слой заведомо пуст), терм-микроблок проверяет только введённое ранее; ритуал финиша включает «ответ с единицей измерения». На «не помню» по букве/термину первый ход — английский якорь («скажи по-английски — первая буква?»), показ только после; алфавит повторяется через «дано» каждой задачи, не карточками.
10. **RU-микропоправки (Николь; решение Артёма 2026-08-24)**: явную ошибку-правило в её сообщении («в двое», «незнаю») можно поправить сразу — одной строкой в скобках после «✅ верно», максимум 1–2 за сессию, без встречного вопроса. Опечатки не трогать; рядом с математической ошибкой или затыком — не поправлять. Всё остальное — молча в harvest-лог (см. Логирование). Если сообщения станут короче — правило снять.

## Fabrication guard

Каждое сообщение заканчивается вопросом — реплики игрока не пишутся никогда, ни как пример без пометки «демо», ни как продолжение диалога. Сработал хук — процитировать, переспросить, ничего не засчитывать. Перед логированием сверить каждый засчитанный ответ с user-записями сырого JSONL; расхождения — инцидент-блоком в лог.

## Логирование — после сессии

Запись в месячный лог той же структурой: строка **Тайминг** из таймстемпов транскрипта (общая + по блокам; длинные паузы — «пауза, причина неизвестна», не «долго думала») · таблицы результатов · Ошибки · Паттерн · План на следующую сессию. Статусы тем в плане (A/B, ru_terms) обновить, если тема закрыта/продвинута; история остаётся в логе.

**RU-harvest (Николь)**: тем же проходом по сырому JSONL собрать орфографические ошибки из её сообщений в `diagnostics/nicole_ru_writing_from_sessions.md` (правила отбора — в шапке файла: опечатки и пунктуация чата — шум, в инвентарь не идут). Введён 2026-08-24 — её письмо в сессиях = холодное производство русского для RU-трека.

## Forbidden

- Дорешивать её задачу; ответ открытого задания на экране
- Демо до холодной проверки
- Фрейм «новый приём» для форматных тем — подавать как «так требуют записывать на контрольной»
- Мышь для письменной работы; бумага+фото — только таймированные прогоны и пробники
