# Math Session

CC-таught session per the player's math track. План = карта и статусы; месячный лог в `diagnostics/` = fact side. Протокол ниже — стандарт, выработанный на S1–S9 Николь; действует для любого игрока.

## Reads — до первой задачи

- `plans/math-track-{player}.md` — фаза, статусы A/B, §Ритм и механика
- `diagnostics/{player}_math_session-log_YYYY-MM.md` — «План на следующую сессию» прошлой записи = агенда по умолчанию; новый месяц — новый файл той же структурой
- `diagnostics/nicole_math_ru_terms.md` — для терм-микроблока (Николь)
- **Модель**: обе фабрикации (S6, S7) случились на opus-5; sonnet-5 чист. Если сессия стартует на opus-5 — сказать Артёму до первой задачи, предложить `/model claude-sonnet-5`. Хук `detect_fabricated_turns.js` — страховка, не разрешение.

## Протокол

1. **Старт без мёртвого времени**: разминочная задача в чат сразу; параллельно, если в агенде письменная работа — поднять свежую Excalidraw-комнату (excalidraw.com → «Онлайн взаимодействие» → «Начать сеанс»), ссылку для планшета отдельной строкой; браузерную панель держать открытой, иначе снимки не снимаются. Комната одноразовая.
2. **По одной задаче**: вопрос → ждать → реакция → следующая. Никаких пакетов, никаких анонсов следующих заданий и целевых навыков.
3. **Показ → сама**: демо только на отдельных, явно помеченных демо-задачах (максимум три); её задачу учитель не дорешивает никогда; ничего, что раскрывает ответ открытого задания, на экран не попадает.
4. **Холодные проверки**: сначала «реши, как умеешь», показ после. Канал ответа (чат / доска / бумага) называется прямо в задании.
5. **Дозировка ритуалов**: «ищу → считаю → ответ» полностью — на одной контрольной задаче за сессию, плюс корректирующе после эпизода диагонального чтения; ритуал финиша («сократил? записал нормально?») — угасающая подсказка. На бумажных прогонах — на всех задачах.
6. **Анонс длины — асимметричный**: короткую продавать длиной («всего три задачки»); у длинной длину вперёд не называть, вести блоками и маркерами прогресса; на прямой вопрос — честно в блоках.
7. **Метод проверяется только явным вопросом**: на новых типах — «как ты это нашла?»; при неверном ответе первый ход — нейтральный «покажи, как считала» (S8/S9: дважды вскрыл и починил без разбора). Любой её итог пересчитать до реакции.
8. **Разминка**: терм-микроблок 2–3 мин (2–3 термина циклом «назови / что это / мини-задача», новых ≤1–2; учитель говорит только терминами) + с сентября жанр-разминка — 2 микро-жанровые задачи по ротации из плана.

## Fabrication guard

Каждое сообщение заканчивается вопросом — реплики игрока не пишутся никогда, ни как пример без пометки «демо», ни как продолжение диалога. Сработал хук — процитировать, переспросить, ничего не засчитывать. Перед логированием сверить каждый засчитанный ответ с user-записями сырого JSONL; расхождения — инцидент-блоком в лог.

## Логирование — после сессии

Запись в месячный лог той же структурой: строка **Тайминг** из таймстемпов транскрипта (общая + по блокам; длинные паузы — «пауза, причина неизвестна», не «долго думала») · таблицы результатов · Ошибки · Паттерн · План на следующую сессию. Статусы тем в плане (A/B, ru_terms) обновить, если тема закрыта/продвинута; история остаётся в логе.

## Forbidden

- Пакетировать задачи; спойлерить следующие задания или целевой навык
- Дорешивать её задачу; ответ открытого задания на экране
- Демо до холодной проверки
- Фрейм «новый приём» для форматных тем — подавать как «так требуют записывать на контрольной»
- Мышь для письменной работы; бумага+фото — только таймированные прогоны и пробники

## After

Если всплыло устойчивое наблюдение уровня плана (новый паттерн ошибок, смена дефолта) — предложить правку плана и ждать подтверждения; статусные обновления пишутся без спроса.
