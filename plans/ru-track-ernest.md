## Формат сессии (внутренняя рамка ~60 мин — Эрнесту длительность НЕ называть)

**Правило подачи (Артём, 2026-08-19, после S1)**: длительность сессии ребёнку не анонсируется никогда — «сегодня ~час» пугает и срывает старт (S1 брошена на середине, возврат через сутки со скрипом). Старт = «короткая разминка» и сразу первый вопрос; блоки подаются по одному («ещё блок?»); финиш на подъёме. Естественная точка выхода ~25–30 мин — валидный финиш, хвост уходит в следующую сессию, план сдвигается без драмы. Час ниже — планировочная рамка Артёма.

Артём просил: **подробно и понятно, с тестами**. Стандартный час:

1. **Разминка-повтор** (5–7 мин) — 3–4 холодных вопроса по прошлым сессиям + 1–2 из орфо-нестабильности (пре/при, дефис, числительные, корни — так spaced-review идёт без отдельных сессий).
2. **Объяснение №1** (12–15 мин) — механизм прозой, живые примеры, от его чутья к термину. Не таблицей — рассказом, таблица в конце как шпаргалка.
3. **Практика** (8–10 мин) — один вопрос за раз, разбор каждой ошибки: почему.
4. **Объяснение №2 / углубление** (8–10 мин).
5. **Практика** (8–10 мин).
6. **Мини-тест** (8–10 мин) — 8–10 холодных вопросов по теме сессии, без подсказок; счёт в лог.

Протоколы (обязательные): длительность не анонсировать, блоки по одному · один вопрос за раз, никогда пачкой · показ → сам (образцы на демо-примерах, с N-го — сам) · никаких меток «что проверяем» на вопросах мини-теста · ответы ученика не дописывать (fabrication guard, сверка по JSONL при сомнении) · Тайминг-строка в лог (общее + по блокам, считается молча по timestamps) · объяснения по-русски.
